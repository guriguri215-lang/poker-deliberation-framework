# ユーザー資料置き場

公開リポジトリへ含めない資料や自作ツールを、このフォルダへ置いてください。Codexは依頼に関連する場合に限り、必要な範囲を参照します。

- この`README.md`と`.gitignore`以外は、ファイル・サブフォルダともGitから無視されます。
- 内容は未検証のユーザー提供情報として扱い、公開情報として引用・再配布しません。
- コード、マクロ、実行ファイルは自動実行しません。
- 内容を外部サービスへ送信しません。外部送信が必要な場合は、対象を示して事前に承認を求めます。
- APIキー、パスワード、個人情報などの秘密情報は置かないでください。Gitの無視設定は、秘密情報の安全な保管を保証するものではありません。

このフォルダ内の資料をコミットする必要が生じた場合も、先に権利と公開可否を確認してください。
